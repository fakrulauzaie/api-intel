## Positioning

api-intel provides evidence-backed blast radius for legacy NestJS systems. It proves
supported static paths to potential side-effect operations and reports exactly where
proof stops. It does not execute a target application or claim complete runtime
reachability.

## Migration notes

This is the first published public prerelease, so there is no supported
published version to upgrade from. Existing private-development users should:

1. run `api-intel doctor <repository>` and resolve only actionable readiness gaps;
2. keep version-4 configuration and explicitly configured critical-section wrappers;
3. regenerate analysis rather than editing a prior artifact or treating an old graph
   as current evidence; and
4. compare schema versions independently instead of assuming package-version lockstep.

Alpha CLI, configuration, report, and schema contracts may change. A later change to a
supported reader or workflow must include explicit migration guidance.
