## Bundled JavaScript

The GitHub Action and GitLab CI adapters are generated with `@vercel/ncc`. Each output
directory contains `THIRD_PARTY_LICENSES.txt`, generated by ncc from the exact modules
included in that bundle. The same directory also contains this notice, the project
`LICENSE`, and `dependency-license-inventory.json`.

`@modelcontextprotocol/server@2.0.0` declares MIT in its package manifest and ships a
license file describing its ongoing Apache-2.0/MIT transition. The complete packaged
text—not a simplified single-license claim—is retained in the ncc license aggregate
when MCP server code is present in a bundle and is fingerprinted in the dependency
inventory.

## OCI image boundary

The GitLab adapter image additionally contains its selected Node/Debian base, `git`,
CA certificates, npm, and pnpm. Their license material is not represented by the npm
inventory in this repository. Debian package copyright files remain under
`/usr/share/doc`, Node's license remains in the base image, and globally installed npm
and pnpm packages retain their packaged license files. A public image release must
also preserve a per-image SBOM, exact base digest, and any corresponding-source or
source-offer material required by those layers. The repository audit alone must not be
represented as legal clearance for an arbitrary `NODE_IMAGE`.
